# Reproducing the research

This guide describes the supported path from a clean checkout to the public Markdown reports. The workflow is deliberately sequential. Data acquisition and every analysis step fail when a required input is missing or invalid.

## 1. Create the environment

Python 3.11 or newer is required.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

On macOS or Linux, activate the environment with `source .venv/bin/activate` and use the same `python` commands.

## 2. Refresh market data

From the repository root:

```powershell
python scripts/refresh_data.py
```

This downloads and validates:

- CBOE VIX, VIX3M, and VIX9D history
- CFE VX contract histories
- Split-adjusted VXX and UVXY histories from yfinance

The command writes raw downloads under `data/raw/` and normalized panels under `data/interim/`. The default run enforces the configured coverage window. Use `--allow-incomplete-coverage` only when inspecting a partial download; the resulting data is not a valid full research input.

The source configuration lives in `config/data_sources.yaml`. To use a separate data location or configuration file:

```powershell
python scripts/refresh_data.py --data-dir PATH --config PATH
```

## 3. Build the signal panel

```powershell
python scripts/run_signal.py
```

This reads the validated index and contract panels, constructs the constant-maturity curve and signal features, and writes `data/processed/signal_panel.parquet`. The latest row is printed to the terminal.

To inspect a specific observed date:

```powershell
python scripts/run_signal.py --date 2025-04-14
```

Use `--data-dir PATH` when the input and output data directory is elsewhere.

## 4. Run the frozen Sprint 3 gate

```powershell
python scripts/run_sprint3_gate.py
```

The gate reads the processed panel, VX contracts, split-adjusted VXX history, and `config/signals.yaml`. It writes the Markdown report and machine-readable artifacts under `results/`. The report includes input hashes, the frozen parameters, annual out-of-sample metrics, stress windows, and the precommitted verdict.

The current public result is `NO-GO`. The command does not search for replacement thresholds.

For a separate output directory:

```powershell
python scripts/run_sprint3_gate.py --data-dir PATH --results-dir PATH --config PATH
```

## 5. Run attribution

```powershell
python scripts/attribution.py
```

This reconstructs the same frozen proxy and decomposes the out-of-sample result into carry, directional movement, transition buckets, annual contributions, and worst days. It writes `attribution_summary.md` plus CSV and parquet detail files.

The attribution is forensic. It does not change the gate or fit new parameters.

## 6. Run the equity overlay analysis

```powershell
python scripts/computation_C.py
```

The overlay uses the same frozen thresholds and evaluates SPY total-return exposure from 2018 onward. By default it attempts to retrieve SPY history with yfinance. To run without network access, provide a local CSV with `Date` and `Close` columns:

```powershell
python scripts/computation_C.py --offline --spy-source data/raw/etp/SPY.csv
```

The output includes full-period and 2022-only metrics, along with `overlay_summary.md`, CSV metrics, and a parquet daily-return series. The de-risking question was formed after the short strategy failed and is labelled as post-hoc in the report.

## Output policy

The selected Markdown reports are useful for browsing and may be tracked as public snapshots:

- `results/sprint3_gate.md`
- `results/attribution_summary.md`
- `results/overlay_summary.md`

Downloaded data, parquet panels, CSV detail files, notebook outputs, caches, and local environments are ignored. They can be regenerated by the commands above and are not part of the public source snapshot.

## Troubleshooting

### A command cannot import `vixharvest`

Use the project interpreter after installing the package in editable mode:

```powershell
python -m pip install -e ".[dev]"
```

The scripts also add the repository `src/` directory when invoked directly, but third-party dependencies still need to be installed.

### A required parquet or CSV file is missing

Run the refresh command first, then run `run_signal.py` to build the processed panel. Gate and attribution require both the panel and the contract history. The gate also requires the split-adjusted VXX CSV.

### CBOE data is stale or its schema changed

The ETL treats an HTTP success with stale content as a failure and validates the expected columns. Check the source endpoint and update `config/data_sources.yaml` only after verifying the replacement format. Record material source changes in `docs/DATA.md` or `data/ANOMALIES.md`.

### Coverage validation fails

The public CFE history begins in 2013, while the original plan requested 2007. The current gate uses 2013-2017 for fitting and 2018 onward for the formal out-of-sample period. Do not silently splice an unverified provider into the history.
